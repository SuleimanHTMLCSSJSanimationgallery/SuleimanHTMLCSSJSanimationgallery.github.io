## 🚀 Features

- **57 Interactive Projects**: Comprehensive showcase of modern animations, 3D perspective transformations, glassmorphism UI components, dynamic calendars, clocks, and templates.
- **In-Browser Sandboxed Preview**: Test and run animations directly inside modal viewports without navigating away.
- **Real-Time Instant Search**: Fast search filter by name, category, or technical tag.
- **Adaptive Dark / Light Themes**: Theme toggle with persistence across sessions.
- **Multi-Device Responsive Layout**: Flawless visual presentation on desktop, tablet, and mobile screens.
